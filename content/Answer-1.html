Answer-1

如何再一次使用

1.更改網路ipv4~ipv6

2.啟動nginx

3.在全球資訊網打入 localhost 如果可以 輸入localhost/reeborg //讓他可以讀到本地資料夾

4.記得 在管理員命令列輸入"taskkill /IM nginx.exe /F" 關掉 nginx

5.去y:\tmp\s 安裝pip install waitress 後啟動python start.watress.py 後啟動nginx 在看是否能啟動動態網頁https://w13.mde.nfu.edu.tw/


6.關閉:Ctrl + C，關閉waitress 後在管理員命令列輸入"taskkill /IM nginx.exe /F" 關掉 nginx

如何第一次使用

1.更改網路ipv4~ipv6

2.啟動nginx

3.在nginx html 資料夾中 git clone https://github.com/mdecycu/reeborg.git //這樣nginx 才能在網頁中讀到資料

4.在全球資訊網打入 localhost 如果可以 輸入localhost/reeborg //讓他可以讀到本地資料夾

5.取得簽章 用certbot.7z 取得 //記得 在管理員命令列輸入"taskkill /IM nginx.exe /F" 關掉 nginx

6.檢查是否有w13.mde.nfu.edu.tw//在命令列輸入"nslookup" 後輸入"w13.mde.nfu.edu.tw"
再下載certbot.7z 後安裝certbot

7.掀開NGINX
安裝certbot的位置 打開 run.bat 管理者命令列輸入 certbot certonly --standalone --register-unsafely-without-email最後綁定"w13.mde.nfu.edu.tw"

8.把證書：
C:\Certbot\live\w13.mde.nfu.edu.tw\fullchain.pem
私鑰：
C:\Certbot\live\w13.mde.nfu.edu.tw\privkey.pem
等等 丟到 nginx>>conf 資料夾中

9.在nginx >> conf 資料夾中 找到 nginx_conf 並把他改只有老師提供的
其中 server改成W13
ssl_certificate F:/wcmtw/nginx-new/nginx-1.28.0/conf/fullchain.pem;
ssl_certificate_key F:/wcmtw/nginx-new/nginx-1.28.0/conf/privkey.pem;

10.建立一個start.watress.py 老師有給讓你的 Flask 應用一直運作中，能被 nginx 反向代理到外網。

11.去y:\tmp\s 安裝pip install waitress 後啟動python start.watress.py 後啟動nginx 在看是否能啟動動態網頁https://w13.mde.nfu.edu.tw/


12.關閉:Ctrl + C，關閉waitress 後在管理員命令列輸入"taskkill /IM nginx.exe /F" 關掉 nginx
